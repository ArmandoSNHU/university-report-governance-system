# Academic Sample Dataset

This folder contains fictional academic records for University Report Governance System.

Dataset contents:

- `students.csv` - 30 made-up students with calculated GPA.
- `professors.csv` - 10 made-up professors.
- `courses.csv` - 10 courses assigned to professors.
- `grades.csv` - 120 course enrollment records, four per student.

All grades are passing. Student GPA values are calculated from the grade points in `grades.csv`.

This data is safe for public demonstration and does not represent real people, institutions, or academic records.
