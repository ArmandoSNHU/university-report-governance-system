# Security Policy

University Report Governance System uses fictional sample data and does not connect to real systems.

## Reporting Security Issues

If you find a security issue in the project code, open a GitHub issue with enough detail to reproduce the problem. Do not include real credentials, production data, student records, employee records, or other sensitive information.

## Data Handling Expectations

- Do not commit production exports.
- Do not commit credentials or connection strings.
- Do not commit personally identifiable information.
- Keep sample data fictional.
- Treat report metadata as potentially sensitive if it describes real institutional processes.
